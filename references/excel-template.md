# 空白报销单与公司原模板

公共模板 `../assets/报销单-空白.xlsx` 保留单页差旅报销表的结构，已清空个人信息及历史明细。原始带历史数据的模板只留作者本机；其他使用者优先用自己当前公司的版本。模板内容是格式参照，不是本次报销事实。

当前公共模板工作表 `差旅报销单 (5)`，区域 `A1:K13`，明细第7—10行。更换模板后重新检查，不能盲写旧坐标。

| 位置 | 填写及公式 |
| --- | --- |
| A1:K1 | 保留标题 |
| A2:K2 | 本次部门、报销日期和按公司口径的附件张数 |
| B3:K3 | 当前使用者姓名 |
| A4:K4 | 本次实际起止日期，跨年写完整年月日 |
| A7:B10 | 每段月份及日期标签，例如 `15—17`，不追加“15晚” |
| C7:C10 | 每段真实起讫地点，逐笔路线放底稿 |
| D7:D10 | 每段已确认计补天数，不是交通段数或日期标签跨度 |
| E7:H10 | 机票、铁路/长途等车费、市内交通、本人承担住宿 |
| I7:I10 | 有效行按该使用者已确认日标准写 `=D7*标准` 等；空白模板不预设任何人的补助标准 |
| J7:J10 | 已确认的业务退改签等其他费用 |
| K7:K10 | `=SUM(E7:J7)` 等行小计 |
| D11:J11 | 各列 `=SUM(D7:D10)` 等；包含“其他”列 |
| K11 | `=SUM(K7:K10)` |
| D12:K12 | `=K11`，保留原中文大写数字格式，核对实际显示 |
| A13:K13 | 主管/会计空白，只填本次报销姓名，不代签 |

默认单人。多人报销先确认计量方式；不要把“多人×天数”塞成自然日数。周末个人休息不计补助；实际出差的周末按公司确认规则。前晚准备费可并入后段，但不因此增加计补天数。

示例（说明方法，不是每次固定行程）：8—13日连续出差为第一行6个计补日，中间14、15日个人时间；15日已确认准备住宿并归后段，第二行日期写15—17，D列仅计16、17日2天。日标准若已确认为80，补助分别480和160，合计640。其他任务按自己真实行程分段，不套两行或8天。

旧原模板曾有D11只统计一行、J11缺合计的问题。公共模板已改为完整第7—10行；如使用私人原模板，核实影响本次的公式并在输出副本修正。超过4段可合理汇总完整行程，确需扩行则同步样式、总计、中文大写引用、签字区和打印范围，不能丢第5段后的费用。

合并区域只写左上角。金额用数值，保留边框、字号、列宽、合并、A4竖向打印。只清输入和过期公式，不能误清表头或合计区。缺资料不是已确认0元；无支出需有事实依据。

验收：逐笔底稿→类别与分段→行小计→类别合计→K11→飞书总额全部对账；补助按去重计补日期计算。重算后看结果，不只看公式字符串。可视核对日期、金额、大写金额、签字及打印不截断。新版修改要有版本号，上传只用当前已确认Excel。
