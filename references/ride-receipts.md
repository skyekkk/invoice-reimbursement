# 顺风车、出租车与补充凭证

先检查使用者的本地公司规则：只有明确允许其他真实行程发票补充，才按本流程；未确认时问一次，已确认则复用，不逐票再问。此规则是使用者确认的公司处理方式，不是通用财务或税法结论。

## 判别与记账

按实际乘坐日期、城市、上下车地点、支付订单与已知行程判断。开票日可能晚于乘坐日；字母A/B、邮件标题及发票金额不能单独证明是哪笔费用。有依据就自行分类，只把无法可靠匹配、金额冲突及可能重复使用的项目集中请用户确认。

分开记录两份信息：

- 实际费用：日期、路线、实际支付（含已付高速费）、报销分段、订单/截图/真实行程单、拟申报额。
- 补充发票：票号、真实原日期和路线、价税合计、来源、分配到哪笔实际费用及金额、可核实的历史报销使用情况、未分配差额。

**申报额按真实应报支出，不加上补充发票票面，不因补票超额而提高报销。** 同票不能既作本次滴滴真实费用，又支撑另一笔顺风车；一张票多项分配总额不能超票面。先核对已提供历史记录，不能声称检查了未取得的全部历史报销。

票面不足列缺口继续查新票。票面略大可以列差额不申报，不需要凑到分毫相同，也不为了凑数找更多票。例：顺风车实际350.00、补充票357.17，只报350.00，余7.17不申报；出租车实际9.40用10.50补充，只报9.40，余1.10不自动再分给顺风车。不同费用各自匹配，不能凭“总额看起来打平”掩盖重复分配。

高速费若已含实际支付总额，不能另加。行程单的车费与另外实际支付的高速费若分列，则按可核实总支出对账。不得修改原发票/行程单，也不得把其他日期地点的发票命名成本次真实行程。

## 上传与本地留存

| 文件 | 本地 | 飞书 |
| --- | --- | --- |
| 本次顺风车真实行程单 | 保留 | 上传 |
| 补充顺风车的滴滴/其他网约车发票 | 保留 | 上传，命名明确“顺风车费用补充发票” |
| 这些补充发票对应的原网约车行程单 | 保留并用于来源核对 | 不上传 |
| 本次真实滴滴或其他网约车发票 | 保留 | 上传 |
| 本次真实网约车发票对应行程单 | 保留 | 默认不上传 |
| 出租车实际付款截图 | 保留 | 作为真实支出凭证上传 |
| 该出租车的补充发票 | 保留 | 上传，注明对应用途 |
| 铁路、航空等其他凭证 | 保留 | 按真实凭证要求，不受网约车行程单筛选规则影响 |

同邮件的发票和行程单全部可下载，本地核对后筛选上传。混合PDF需识别页码，无损提取完整发票页；原件和映射保留。可靠分离不了则列明问题，不猜页码、不随意删页。

在表单允许的说明处或独立说明附件中列：实际费用和凭证、补充发票真实来源/票号/分配、未申报差额。主“内容”仍与付款类别一致。来源不同不能隐去，但无需在文件名塞满票号、旧日期、多个无关材料；详细对应表放说明，文件名清楚表达材料身份即可。
